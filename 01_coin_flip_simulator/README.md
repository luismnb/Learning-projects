# Coin Flip Simulator

Simple Python project that simulates coin flips and analyzes how the observed probability changes as the number of trials increases.

## What it does
- Simulates repeated coin flips
- Counts heads and tails
- Stores cumulative results
- Calculates the observed percentage of heads
- Plots how the result converges toward the theoretical 50% probability

## Concepts practiced
- Python loops
- Conditionals
- Lists
- Random simulations
- Basic probability
- Matplotlib

## Goal
Understand through simulation how experimental probability behaves as the number of trials increases.
