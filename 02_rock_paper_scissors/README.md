# Rock Paper Scissors

A simple Python game where the user plays Rock, Paper, Scissors against the computer.

## What it does
- Lets the player choose Rock, Paper, or Scissors
- Generates a random choice for the CPU
- Determines the winner of each round
- Keeps track of the score
- Allows multiple rounds
- Shows the final score when the player decides to stop

## Concepts practiced
- User input
- Random choices
- `if`, `elif`, and `else`
- `while` loops
- `break` and `continue`
- Counters
- Basic game logic

## Goal
Practice control flow and user interaction by building a simple command-line game.
